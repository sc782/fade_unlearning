# fade-unlearncanvas

FADE on [UnlearnCanvas](https://github.com/OPTML-Group/UnlearnCanvas) (style
unlearning in text-to-image diffusion): how far a Stable Diffusion v1.5 model that has
unlearned an artistic style is, in distribution, from a retain-only oracle that was
never trained on that style -- measured on images of the forget style generated by
each. See the [top-level README](../README.md) for FADE in general.

This directory is a self-contained fork of UnlearnCanvas that adds FADE, the
retain-only oracle training it depends on, and the 5 baseline unlearning methods FADE
is evaluated on.

## The FADE metric

For a forget style with retain-only oracle r and evaluated model u:

```
term1 = KL(r || u)      bounded on images generated by r
term2 = KL(u || r)      bounded on images generated by u
FADE  = term1 + term2
```

Images come from the stochastic DDIM sampler (eta = 1, 100 steps, classifier-free
guidance scale 9, 512px) with the prompt `"A {object} image in {style} style."`. Each
sampler step x_tau -> x_prev is Gaussian, with a variance sigma_tau^2 shared by both
models and a mean linear in the guided noise prediction
`eps~ = eps(x, "") + 9 * (eps(x, c) - eps(x, ""))`. So the KL between the two models'
steps has a closed form, and by the chain rule and the data processing inequality, the
KL between the images they generate is bounded by the sum of the step KLs along the
sampling chain:

```
KL(p_r(x_0 | c) || p_u(x_0 | c))  <=  E_{x_T..x_1 ~ r} [ sum_tau  w_tau * || eps~_r(x_tau, tau, c) - eps~_u(x_tau, tau, c) ||^2 ],
w_tau = c_tau^2 / (2 sigma_tau^2)
```

where c_tau is the coefficient of eps~ in the step mean. The latents x_tau are r's own
sampling chain -- the bound is computed while r generates its images -- and both
models' predictions are guided, as in sampling. All 100 steps are used, so the only
estimation error is the Monte Carlo average over images.

FADE is reported in **nats per latent dimension**: the bound is divided by the latent
size (4 x 64 x 64 at 512px), which keeps values comparable across image resolutions.
Each term is the mean over 2000 images of a style (100 seeds x 20 object classes).

## Checkpoints

Everything FADE needs is published in the
**[FADE UnlearnCanvas Checkpoints](https://huggingface.co/collections/sungjuncho/fade-unlearncanvas-checkpoints-6a61761b36b8f53ae21b57b8)**
collection. `scripts/download_checkpoints.py` fetches them into the paths the code
expects (converting to the `{"state_dict": ...}` checkpoint format used throughout);
`compute_fade_all.sh` calls it on demand, and a checkpoint you train yourself at the
same path is used as-is.

| model | local path (relative to `fade-unlearncanvas/`) |
|---|---|
| full: fine-tuned on all 50 styles (the starting point for unlearning) | `ckpts/diffusion/compvis/style50/compvis.ckpt` |
| retain-only oracles, seeds 0-2: fine-tuned without Monet, Picasso, Van Gogh | `diffusion_model_finetuning/logs/retain_seed{0,1,2}.ckpt` |
| unlearned: 5 methods x 3 forget styles, each starting from the full model | `machine_unlearning/<method>/...` (see `download_checkpoints.py`) |

Methods: **CA** Concept Ablation, **EDiff** EraseDiff, **ESD** Erased Stable
Diffusion, **SalUn** Saliency Unlearning, **SHS** Scissorhands. Forget styles: Monet,
Picasso, Van_Gogh.

```bash
cd diffusion_model_finetuning
./scripts/download_checkpoints.sh                 # everything (~95GB)
./scripts/download_checkpoints.sh --only retain   # or: full / unlearned
```

## Quickstart

```bash
conda env create -f environment.yaml && conda activate unlearn_canvas
cd diffusion_model_finetuning
./scripts/compute_fade_all.sh 0 1 2      # GPU ids; styles are spread over them
```

For each forget style, `retain_seed0` is the reference oracle r. It generates images
once, scored against every other model (term1), and every other model generates images
scored against it (term2). The other models are retain seeds 1 and 2 (the floor
between oracles that never saw the style), the full model before unlearning, and the 5
unlearned models. Each direction is saved as `output_fade/<style>/<A>_vs_<B>.pt`
(images from A, with a per-image `diffs` tensor), the images to
`output_images/<model>/<style>/`, and `aggregate.py` sums the two directions into
`output_fade/fade_results.csv` and prints the table.

`NUM_SEEDS=10 ./scripts/compute_fade_all.sh 0` uses 10 seeds (200 images per
direction) instead of 100. Single pair, both directions:

```bash
python compute_fade.py --theme Monet --driver retain0=logs/retain_seed0.ckpt --others ESD=<ckpt>
python compute_fade.py --theme Monet --driver ESD=<ckpt> --others retain0=logs/retain_seed0.ckpt
python aggregate.py
```

Sampling is the expensive part. On one RTX PRO 6000 (96GB), a model sampling and
scored against one other takes about 2.7 s per image, and `retain_seed0` scored
against all 8 others about 12 s per image, so the full run is about 18 hours per style
on one GPU. The UNet runs in
fp16 autocast, as in image sampling (the bound changes by under 0.2% in fp32).

`environment.yaml` pins PyTorch 1.11 / CUDA 11.3, as UnlearnCanvas does. GPUs that
need a newer CUDA (e.g. Blackwell) need PyTorch 2.x; `compute_fade.py` runs with
`torch==2.7.1` (CUDA 12.8), `pytorch-lightning==1.7.7` and `torchmetrics==0.11.4`.

## Results

`NUM_SEEDS=10` (200 images per direction), against `retain_seed0`, in nats per latent
dimension (term1 + term2):

| style | retain_seed1 | full | CA | EDiff | ESD | SalUn | SHS |
|---|---|---|---|---|---|---|---|
| Monet | 0.29 | 3.24 | 3.59 | 7.13 | 4.29 | 4.08 | 14.01 |
| Picasso | 0.35 | 2.63 | 2.99 | 6.28 | 4.33 | 3.88 | 13.09 |
| Van_Gogh | 0.34 | 3.88 | 3.49 | 6.94 | 4.62 | 4.13 | 15.60 |

## Training from scratch

```bash
cd diffusion_model_finetuning
./scripts/train_full.sh [GPUS]         # full (50-style) model; GPUS defaults to 0,1,...,7
./scripts/train_retain.sh 0 [GPUS]     # retain-only oracle, seed 0 (likewise 1, 2); GPUS defaults to 0,1,2,3
```

The 5 unlearning methods are run from the full checkpoint, each from its own directory
under [`machine_unlearning/`](machine_unlearning/) -- see `machine_unlearning/*/README.md`.
Training needs the UnlearnCanvas dataset and the Stable Diffusion v1.5 base checkpoint;
see "Setup" in [`diffusion_model_finetuning/README.md`](diffusion_model_finetuning/README.md).

## Files

| path | |
|---|---|
| `diffusion_model_finetuning/compute_fade.py` | one FADE direction: samples images from one model and bounds its KL to any number of others |
| `diffusion_model_finetuning/aggregate.py` | sums the two directions into the FADE table |
| `diffusion_model_finetuning/constants/const.py` | style and class lists, incl. the retain-only style list |
| `diffusion_model_finetuning/scripts/` | full pipelines (FADE, training) and checkpoint download |
| `diffusion_model_finetuning/evaluation/` | UnlearnCanvas's classifier accuracy / FID (secondary metrics) |
| `diffusion_model_finetuning/sampling/` | UnlearnCanvas's image generation |
| `machine_unlearning/` | the 5 baseline unlearning methods |
